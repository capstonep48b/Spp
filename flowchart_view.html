Alur Rinci Integrasi Midtrans Payment Gateway (Snap API & Webhook Notification)
Protokol Transaksi Aman (HTTPS + Signature SHA-512)
1
Pilih Tagihan & Request Token
Wali Murid memilih bulan SPP yang tertunggak, lalu klik tombol bayar online. Frontend memanggil API inisiasi pembayaran.
POST /api/payment/create
{ nis, bulan, tahun, nominal }
2
Generate Midtrans Snap Token
Backend menyusun order id unik dan memanggil endpoint Snap Midtrans menggunakan Server Key rahasia.
midtrans.snap.createTransaction({
  order_id: "SPP-2026-...",
  gross_amount: 150000
})
3
Tampilan Popup Snap Modal
Midtrans Snap Popup muncul di layar wali murid dengan berbagai pilihan channel (BCA VA, BRI VA, GoPay, QRIS, dll).
window.snap.pay(token, {
  onSuccess: (res) => {},
  onPending: (res) => {}
})
4
Webhook Callback Notification
Setelah pembayaran diselesaikan di bank / QRIS, Midtrans mengirimkan notifikasi HTTP POST ke URL callback backend sekolah.
POST /api/midtrans/webhook
{ transaction_status: "settlement",
  signature_key: "..." }
5
Verifikasi & Terbit Kuitansi
Backend mencocokkan SHA-512 Signature. Status SPP otomatis berubah menjadi LUNAS dan kuitansi resmi siap diunduh.
UPDATE pembayaran_spp
SET status = 'Lunas',
    metode = 'Midtrans-VA'
